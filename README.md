# 🏎️ PITWALL – Guia do Grande Prêmio de São Paulo

## 📌 Sobre o projeto

O PITWALL é um site desenvolvido como projeto de estudo de HTML e CSS, com o tema do Grande Prêmio de São Paulo de Fórmula 1, realizado no Autódromo de Interlagos.

O objetivo do projeto é apresentar informações sobre o automobilismo de uma forma moderna e organizada, utilizando elementos visuais inspirados nas equipes e nas corridas de Fórmula 1.

## 💻 Tecnologias utilizadas

- **HTML5:** utilizado para criar a estrutura e organizar o conteúdo do site.
- **CSS3:** utilizado para personalizar o visual, as cores, os espaçamentos, os efeitos e a organização dos elementos.

## 🚦 Funcionalidades do site

O site possui diferentes seções para apresentar as informações:

- **Página inicial:** apresenta o Grande Prêmio de São Paulo, com uma imagem de corrida e algumas informações sobre o circuito.
- **Grid de pilotos:** mostra alguns pilotos da Fórmula 1 e suas respectivas equipes.
- **Classificação:** apresenta uma tabela ilustrativa com posições, pilotos, equipes, vitórias e pontuação.
- **Ingressos:** exibe opções de setores e seus respectivos preços.
- **Formulário:** permite preencher informações como nome, e-mail, telefone, setor desejado, data e observações.

## 🎨 Design

O projeto utiliza um visual inspirado nas corridas de Fórmula 1, com predominância das cores preto, vermelho e branco.

Também foram utilizados efeitos visuais, cartões para os pilotos, tabelas estilizadas e fontes personalizadas para deixar o site mais próximo da identidade visual do automobilismo.

O layout foi desenvolvido para se adaptar a diferentes tamanhos de tela, incluindo celulares e computadores.

## 📁 Organização dos arquivos

- `index.html` – arquivo responsável pela estrutura do site.
- `styles.css` – arquivo responsável pela aparência e estilização.
- `img/` – pasta utilizada para armazenar as imagens do projeto, incluindo a imagem principal do piloto.
